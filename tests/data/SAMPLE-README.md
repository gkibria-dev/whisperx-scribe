# WhisperX Sample Audio

`sample-2-speakers.wav` is a small, self-contained test fixture for the WhisperX transcription pipeline.

- Format: WAV, 16 kHz, mono PCM
- Content: two alternating English speakers
- Purpose: quick functional testing of transcription, alignment, and speaker diarization
- The voices are locally synthesized with eSpeak and are intentionally used as a deterministic test fixture.

Expected speech is documented in `sample-2-speakers.expected.txt`.
